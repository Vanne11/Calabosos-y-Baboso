# `wait` — Pausa dramática

Pausa la ejecución con texto animado.

```jsonc
{
  "type": "wait",
  "text": "El suelo tiembla bajo tus pies...",
  "duration": 2000,                // Milisegundos
  "style": "typing"                // typing | fade | dots
}
```
