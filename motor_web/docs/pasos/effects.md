# `effects` — Aplicar efectos silenciosamente

Aplica modificadores al estado sin interacción del jugador.

```jsonc
{
  "type": "effects",
  "effects": {
    "stats": { "will_to_live": -10 },
    "flags": { "trap_activated": true },
    "inventory": ["mysterious_note"]
  }
}
```
